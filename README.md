# sms_v3

## Seed demo data

This repository includes a Firebase seed script for local/dev Firestore data.

To run it:

1. Ensure `serviceAccountKey.json` is present in the project root.
2. Install dependencies:

```bash
npm install
```

3. Seed Firestore:

```bash
npm run seed
```

Seeded accounts use the password `Password123!`.
